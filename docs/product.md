# memorize-all 구현 기준

2026-10-04 사용자가 전달한 계획의 구현을 승인했다. Android/iOS, 한국어/영어, 로그인 없는 기기 내 학습을 우선한다. 2026-10-05 사용자 선택: 공개 이름 `Memorize All`, Android/iOS 식별자 `com.seorilabs.memorizeall`. 원격 저장소는 아직 없다.

## 이번 실행 범위

첫 검증 단계: 지리·원소·달·커피·와인 각 20개, 총 100개 고유 지식. 16개 카테고리 탐색. 나머지 11개와 1,000개/40개 묶음은 이후 공개 목표이며 확보한 것으로 표시하지 않는다. 출처·사실 버전·표현 버전·한영 문장·검수 상태를 콘텐츠에 둔다. 미검수 표본은 공개 배포 검사에서 차단한다.

오늘 학습, 오답 재시도, 간격 복습, 도감, 한영 전환, 로컬 저장/백업/복구를 제공한다. 2026-10-05 사용자가 수익모델을 **배너광고만**으로 변경했다. 모든 지식과 복습은 무료이며 결제·구독·유료 권한 제한을 두지 않는다. 다기기 동기화와 원격 콘텐츠 배포는 후속 기능이며 현재 출시의 필수 조건이 아니다.

네이티브 루트에 320×50 배너 한 개를 둔다. 관심 선택·학습·해설·완료·탐색·도감·설정·로딩·오류 화면에서 같은 배너 영역을 유지한다. 스크롤 콘텐츠나 버튼을 덮지 않으며 광고가 늦게 도착해도 영역 높이는 유지한다. 광고 개인정보 선택 확인과 SDK 초기화 전에는 광고를 요청하지 않는다. 광고 실패가 학습·저장·복습을 막지 않는다. 웹은 기능 검수용이며 모바일 AdMob SDK를 불러오지 않는다.

## 기억과 측정

초기 정답은 1일 뒤, 이후 성공은 3일/7일/14일/30일 간격. 오답/헷갈림은 연습 상태로 되돌리고 다음 날 복습. 동일 세션에는 최대 1회 재시도하며 간격 성공으로 승격하지 않는다. 최소 7일 간격의 첫 응답 정답만 '시간이 지나도 기억함'으로 표시한다. 정답 revision 변경 시 평가·진도는 새로 시작하되 옛 응답은 이력에 보존한다. 표현 revision 변경은 보존한다.

학습 이벤트는 로컬에만 보관하고 광고 SDK에 전달하지 않는다. Google은 광고 식별자·기기 정보 등을 처리할 수 있다. 첫 응답과 동일 세션 재시도, 7일 이상 지연 첫 응답, 오답 극복, 세션 완료를 분리한다. 실제 사용자 표본 없이 기억 향상·유지율·매출을 주장하지 않는다.
