# Memorize All Android 공개 출시

사용자가 2026-10-20 대화에 제공한 출시 계획의 구현과 검증을 명시적으로 지시했다. 이 문서는 그 승인 범위를 기록한다.

기존 화면과 로컬 저장 키 `memorize-all.state.v1`, schema 1, 지식 ID를 유지한다. 준비된 지리, 원소, 달, 커피, 와인만 노출한다. 관심 선택, 오늘의 10개, 퀴즈와 카드, 도감, 설정, 백업과 복원 흐름은 유지한다. 빈 분야와 검수용 문구를 제거하고 오류 복구와 작은 화면을 검증한다. 새 화면이나 UI 개편은 없다.

콘텐츠는 사실, 한영 문구, 문제당 정답 유일성, 항목별 출처와 이용 조건을 검수한 정확한 스냅샷만 승인한다. 학습 코어, 콘텐츠, 플랫폼 저장과 광고 어댑터, UI 경계를 유지한다. Firebase, 로그인, 서버, 원격 분석은 추가하지 않는다.

배너 한 개만 유지한다. UMP의 canRequestAds 확인과 SDK 초기화 완료 전에 요청하지 않는다. 개인정보 선택 변경, 동의 정보와 SDK 초기화 실패, 재시도는 학습을 막지 않는다. 웹 광고 경계는 대체 구현이며 네이티브 동작 근거가 아니다.

공개 저장소는 `seoleeapps/memorize-all`이다. 원본 로컬 Git과 사용자 파일은 보존하며 공개용 복사본에 개인 계정, 로컬 절대 경로와 비밀값을 포함하지 않는다. 기존 앱 전용 업로드 키를 재사용한다. Linux GitHub Actions에서 일반 PR은 검사, 릴리스 태그는 같은 검사와 서명 AAB 빌드를 수행한다. Expo native 폴더는 config plugin으로 생성한다.

Google Play 기존 `Seolee Apps` 앱 `com.seorilabs.memorizeall`에 무료 성인용 1.0.0을 제공 가능한 모든 국가로 전체 공개한다. versionCode는 라이브 조회 최댓값에 1을 더한다. 같은 운영 광고 AAB를 내부 테스트와 프로덕션에 사용한다. 국가, 정책, 광고 동의 메시지, 개인정보와 지원 URL을 실제 구현과 대조한다.

L3 전체 회귀는 개발 환경으로 수행한다. 사용자가 에뮬레이터와 실기기를 명시적으로 제외했다. RN 기능 목록 v1의 저장과 광고 기반 기능은 승인된 하한 조정으로 개발 환경에서 검수한다. 실제 네이티브 광고 표시, 공유 수신, Play 설치와 16KB 런타임은 미실행으로 남긴다. 중앙 검증기 오류를 숨기거나 실제 SDK 실행으로 바꾸지 않는다.

인수조건: AC-1 전수 승인 콘텐츠 100개와 문제 200개, AC-2 기존 진도와 전체 학습 흐름, AC-3 광고 동의와 실패 복구, AC-4 재현 가능한 Linux 검사와 서명 빌드, AC-5 정책 페이지와 스토어 정보, AC-6 동일 후보의 중앙 검증과 마켓 상태 분리. 테스트, 정적 산출물 검사와 웹 입력 흐름으로 검증한다. 외부 콘솔과 이미지의 선행 실패는 자동 테스트로 만들 수 없어 실제 조회와 시각 검수로 대체한다.

소스 SHA와 AAB 해시를 고정하고 빌드, 업로드, 처리, 심사, 승인, 공개, AdMob 준비 상태를 별도로 기록한다. 필수 검사나 계정/심사 차단은 상태와 남은 조건을 보고한다. 공개 후 실제 설치와 배너 표시는 사용자 확인 범위다. 실패한 후보는 고유한 새 버전 코드로 대체하고 기존 사용자 데이터를 지우지 않는다.
