# 모바일 UI 수정 기준

2026-10-04 · 콘텐츠 수량은 그대로 유지한다.

| 화면 | 목적과 핵심 행동 | 필수 정보·시각 표현 |
| --- | --- | --- |
| 오늘 | 오늘 학습 시작·재개 | 제목 바로 아래 시작 버튼, 수집·복습 수, 3단계 기억 표시 |
| 학습 | 떠올리기 → 답 확인 → 다음 지식 | 작은 뒤로 버튼, 진행 표시, 그림으로 구분되는 앞면/뒷면, 답 확인 후 자기 평가 3개 |
| 탐색·묶음 | 주제를 찾아 학습 시작 | 알아볼 수 있는 주제 그림과 라벨, 발견 개수, 마친 묶음 다시 연습 |
| 도감 | 수집·복습 상태 확인 | 실제 개수, 상태별 빈 화면, 지식 해설의 그림 |
| 설정 | 언어·학습 방식·백업 변경 | 즉시 방식 전환, 백업 확인·취소, 비용·데이터 필수 고지 |

반복되는 영문 머리말과 홈의 두 줄 홍보 문구를 제거한다. 기본 글자는 줄이지 않고 간격과 반복 설명을 줄인다. 큰 글자에서는 카드·평가 버튼을 자연스럽게 늘리고 스크롤을 허용한다. 퀴즈는 선택지를 표시하며, 플래시카드는 답을 확인한 다음 평가 버튼을 표시한다. 자기 평가를 저장한 후 한 번에 다음 카드로 이동한다.

문제 앞면에는 주제 그림만 표시해 답을 노출하지 않는다. 뒷면·해설에는 원소 번호/기호, 달 위상 비교, 수도 관계, 커피 열매의 씨앗, 발효 흐름을 해당 지식에서만 표시한다. 그림은 직접 그린 벡터이며 외부 이미지를 가져오지 않는다. 검수 대기 사실의 승인 상태는 바꾸지 않는다.

진행 중인 문제도 방식을 바꿀 수 있다. 이미 답한 문제는 원래 방식으로 보관하고 다음 문제부터 전환한다. 다시 연습은 지연 복습 정답률에 포함하지 않는다. 기기 저장 성공 전에는 다음 카드로 넘어가지 않는다.

2026-10-05 네이티브 검수에서 320×568 / 글자 1.5배의 홈 시작 버튼이 아래로 밀려 첫 화면에 보이지 않는 문제를 확인했다. 시작 버튼을 제목 바로 아래로 옮기고 방식 선택은 학습·설정에서 제공한다. 영어 도감 탭은 `Atlas`로 줄여 작은 화면에서도 라벨이 잘리지 않게 했다. [전후 실행 근거](android-native-qa.md)를 확인한다.
