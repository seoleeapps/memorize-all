# UI 기능 수정 검증 — 2026-10-04

`fix/study-ui`에서 기존 콘텐츠 100개/문제 200개를 유지한 채 화면과 학습 동작을 수정했다. 네이티브 UI 최종 완료 판정은 보류한다.

## 수정한 문제

- 설정의 플래시카드 선택은 `state.mode`만 바꾸고 진행 중인 `session.mode`는 유지했다. 실제 화면에서 선호 방식 `card`, 활성 방식 `quiz`, 답 공개 버튼 0개/퀴즈 보기 4개를 재현했다.
- 이제 미응답 문제에 즉시 적용하고, 답한 문제는 원래 평가를 보관한 채 다음 문제부터 전환한다. 예전 저장 파일에서 두 방식이 다른 미응답 세션도 읽을 때 복구한다.
- 플래시카드 앞면과 누를 위치를 표시한다. 답 공개 후 자기 평가 3개가 나오며 평가 저장과 다음 카드 이동이 한 번의 저장으로 끝난다. 다시 퀴즈로 바꿨다가 카드로 돌아오면 답은 숨긴다.
- 마친 묶음의 다시 연습, 관심 분야 편집 취소, 도감 필터의 빈 상태, 없는 지식 링크의 복구, 웹 파일 선택 취소 후 버튼 복구를 연결했다.
- 홈·탐색·도감·설정·완료의 반복 영문 머리말을 제거했다. 홈의 두 줄 홍보 문구·반복 설명 대신 짧은 제목과 실제 기록의 3단계 표시를 사용한다. 기본 본문 글자·버튼 크기는 유지한다.
- 벡터 주제 그림, 탭 아이콘, 앞면 뒤집기 그림, 원소 타일·달 위상·나라와 수도 관계·커피 열매 단면·발효 흐름을 표시한다. 정답 그림은 답 공개 이후에만 보인다. 카드의 출처는 평가 버튼 아래에서 펼쳐 볼 수 있다.

## 남은 확인

iPhone 16 Pro / iOS 18.1의 idb 1.1.8은 `SimulatorKit.framework`의 옛 Xcode 경로를 요구해 터치에 실패했다. 별도 작업용 companion에 프레임워크 검색 경로만 지정해도 같은 오류가 났다. 시스템 파일 변경 없이 종료했고 기존 companion은 유지했다. Android는 `adb devices`에서 연결 기기가 없다.

따라서 Android/iOS 실제 터치, 화면 읽기, 큰 글자, 앱 종료 후 오프라인 재시작, 시스템 공유·파일 선택은 아직 통과로 판정하지 않았다. 다음 작업은 콘텐츠 확대에 앞서 이 네이티브 UI 검수다. 서버/콘텐츠 승인/공개 출시는 이 UI 수정의 범위가 아니다. 이후 배너광고 전환과 네이티브 빌드 상태는 [광고와 빌드](advertising.md)를 따른다.
