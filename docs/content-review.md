# 첫 공개판 콘텐츠 검수

2026년 10월 20일 한국 시간에 지식 100개와 양방향 문제 200개를 한국어와 영어로 검수했다. [항목별 근거](../content/evidence/editorial-2026-10-20.json)에는 출처 URL, 자료 안의 위치, 검수한 문제 ID, 다섯 확인 항목과 정확한 콘텐츠 해시가 있다. `content/reviews.json`에 같은 해시의 승인 기록 100개를 남겼으며, 생성 결과에는 미승인 후보가 없다.

| 분야 | 지식 | 문제 | 대조한 자료 |
| --- | ---: | ---: | --- |
| 지리 | 20 | 40 | Wikidata의 현재 P36 수도 관계, 이집트 국가정보원의 수도 설명 |
| 원소 | 20 | 40 | IUPAC의 2022년 5월 4일 주기율표에서 원소 이름, 기호, 원자 번호 1부터 20까지 |
| 달 | 20 | 40 | NASA Science의 위상, 달의 사실, 식, 조석 자료 |
| 커피 | 20 | 40 | National Coffee Association, Specialty Coffee Association, Nespresso, Starbucks의 해당 용어 설명 |
| 와인 | 20 | 40 | WSET의 항목별 설명과 교육 범위, Australian Wine Research Institute의 리스 설명, TTB의 원산지 명칭 설명 |

지리 20개는 [이번 Wikidata 조회](../content/evidence/geography.json)에서 모두 일치했다. 조회 시각, 원천 revision과 수도 entity ID를 보존했다. 정부 청사 이전과 수도 명칭을 혼동하지 않도록 이집트 국가정보원 자료도 확인했다.

수도와 원소 역방향 질문의 한국어 조사를 정리했다. 용어 문제는 가장 알맞은 뜻을 묻도록 했으며, 원두와 생두, 추출과 개별 추출법, 침지와 프렌치 프레스처럼 상위 개념과 하위 개념이 한 문제에 나오는 조합을 제외했다. 에스프레소에 포괄적인 필터 설명이 함께 나오던 조합, 달의 바다에 충돌구가 함께 나오던 조합도 제외했다. 필터 커피는 물이 가루와 필터를 통과하는 과정으로 설명하고, 라테와 카푸치노는 거품층 차이를 보강했다. 삭은 달의 밤인 면이 지구를 향하는 위상으로 설명하고, 상현과 하현은 겉보기 반달 모양을 뜻하도록 다듬었다. 와인 원산지 명칭은 포도의 지리적 원산지로 좁혔다.

지식 ID, 정답 사실과 `factRevision: 1`을 유지했다. 질문과 문장이 바뀌었으므로 전체 항목의 `textRevision`은 2다. 생성기의 각 항목별 출처 매핑도 고쳤다. 일반 홈페이지 연결이나 출처 식별 대기 문구를 승인 근거로 사용하지 않았다.

문장과 모식도는 앱의 자체 표현을 사용한다. Wikidata의 구조화 사실은 CC0이며, 설명 문서를 그대로 복제하지 않는다. IUPAC 도표의 그림과 배치, NASA 사진과 로고, 커피 및 와인 기관의 문장과 사진을 앱에 복제하지 않는다. NCA, WSET 등의 사이트를 공개 라이선스로 간주하지 않는다. 이들의 자료는 사실 대조와 출처 링크로만 사용한다. 기관의 제휴나 추천을 뜻하지 않는다. 구체적인 이용 범위와 확인 링크는 항목별 승인 기록과 검수 근거의 `rights`에 남겼다.

배치의 시작과 종료 시각을 실제로 기록했다. 공식 자료 조회와 수정이 포함된 경과 시간은 313.452초다. 개별 항목의 시간을 따로 재지 않았으므로 `seconds`는 `null`이며, 이 시간을 항목마다 나누어 실측값처럼 저장하지 않았다. 사람의 검수 단가나 1,000개 제작 시간으로 환산하지 않는다. `review-content.py`는 기존 개별 시간 기록을 유지하면서, 종료 시각과 경과 시간, 해당 항목의 출처와 해시, 다섯 확인 항목이 일치하는 완료 배치도 받을 수 있다.

검증 결과는 다음과 같다.

- 콘텐츠 검수 파이프라인 Python 테스트 3개 통과. 미완료 기록 거부, 정확한 해시만 승인, 미검수 시간을 0으로 보지 않는 조건을 확인했다.
- `npm run check:content -- --release` 통과. 100개 지식과 200개 문제에서 중복 ID, 누락 번역, 중복 보기, 정답 누락과 미승인 후보가 없다.
- 자동 검사는 뜻이 겹치는 정답을 판정하지 못하므로, 위 항목별 의미 검수와 함께 사용한다.

커피 메뉴는 통상적인 따뜻한 음료의 정의다. 지역과 조리법에 따른 비율 차이는 고정 수치로 가르치지 않는다. 와인 제조 설명에는 일반적인 방법을 뜻하는 한정 표현을 유지했다. 조석 시각의 지역별 차이와 달 모식도의 관찰 방향을 실제 관측값으로 주장하지 않는다. 수도 정보는 다음 출시 전에 다시 조회한다. 이 기록은 화면 렌더링, 접근성이나 네이티브 SDK, 기기 실행의 통과 근거가 아니다.
