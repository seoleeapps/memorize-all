# Android 1.0.0 공개 출시 상태

2026년 10월 20일 확인. 공개 출시는 아직 완료되지 않았다. 원본 로컬 Git과 사용자 파일을 보존하고 별도 공개 저장소에서 구현했다.

## 고정한 후보

- 공개 저장소: https://github.com/seoleeapps/memorize-all
- 코드 SHA와 태그: `ad439207a29b4a8d4c809ef99a0219418e6931cb`, `v1.0.0`
- 패키지: `com.seorilabs.memorizeall`, 버전 `1.0.0`, versionCode `3`
- Google Play 개발자: `Seolee Apps`, 개발자 ID `5547060480954653351`
- 무료, 성인 18세 이상, 제공 가능 국가 및 지역 178개 행 전체 선택, 전체 공개 승인
- Firebase, 로그인, 서버와 별도 원격 분석은 추가하지 않았다. 기존 하단 배너 한 개를 사용한다.

PR #5와 #2는 현재 HEAD의 CI 통과와 리뷰 지적 처리, 미해결 thread 0개 확인 뒤 병합했다. GitHub 병합 API가 공개용 no-reply 이메일 두 형식을 거부해 개인 이메일 설정을 변경하지 않고 Git의 일반 fast-forward 병합으로 PR 커밋을 반영했다. 강제 push나 검사 우회 없이 검수한 코드 SHA를 유지했고, 두 PR의 MERGED 상태와 원격 main을 다시 읽었다.

## 변경과 검증

한영 지식 100개와 문제 200개의 사실, 번역, 정답의 유일성, 출처와 이용 조건을 전수 검수했다. 검수 대기 항목은 0개다. 기존 디자인과 지식 ID, factRevision, 저장 키 `memorize-all.state.v1`과 schema 1 진도를 유지했다. 빈 분야와 내부 검수 문구를 정리하고 저장 실패 복구를 확인했다.

이전 버전에서 유효했던 11개 빈 분야를 포함하는 백업은 해당 관심 분야만 정리하면서 진도와 기록을 보존한다. 읽기만으로 원본 저장 값을 덮어쓰지 않는다. 기존 지식 100개와 문제 200개 ID는 유지했다. 모호한 오답을 수정한 10개 문제는 선택지 ID가 달라졌으므로 해당 문제의 오래된 진행 중 세션은 종료하고 새 학습을 시작한다. 기존 학습 기록은 보존한다. 원래 내부 테스트 소스와 fixture의 catalog, 학습 규칙, 저장 코드가 동일함을 Git blob 해시로 대조했다. 실제 이전 선택지를 넣은 백업을 브라우저로 가져와 기록 보존과 새 세션 시작을 검증했다.

최종 SHA에서 lint, TypeScript, Node 28개와 Python 7개, 콘텐츠, 구조와 catalog 재생성 비교, 출시 소스 검사, 웹 export를 통과했다. 독립 검수자가 같은 SHA에서 L3 전체 회귀와 추가 백업 검사를 실행하고 캡처 28개를 직접 확인했다. 브라우저 실행 오류는 0개다. Expo Doctor는 21개 검사를 통과했다. 중앙 before-build와 before-release 검사도 실제 CLI 실행으로 통과했다. 근거는 `docs/qa/independent-ad43920.json`과 `release/evidence/2026-10-20/development-evidence.json`이다.

원본 QA 파일은 체크아웃 밖에 보관하고 압축 안의 모든 파일을 다시 읽어 해시를 대조했다. 최종 SHA의 78개 파일과 메타데이터 정정 전 SHA의 82개 파일을 별도 보관했다. 이전 SHA의 기록을 최종 SHA의 실행으로 바꾸지 않았다. 보관 해시는 `release/evidence/2026-10-20/final-qa-archive.json`에 있다.

릴리스 빌드와 서명 범위를 포함한 교차 코드 리뷰 2회를 마쳤고 수용한 결함을 수정했다. 백업 복원 수정 PR은 별도의 교차 리뷰를 마쳤다. 출처 커밋 차이에 관한 지적은 원본 Git 객체 해시로 소명했다. 공개 사본에서 새로 만든 두 커밋의 작성자 정보는 검증한 백업 뒤 공개용 no-reply로 정정했다. 활성 브랜치의 개인 이메일 부재를 검사했다. 교체된 Git 객체의 GitHub 캐시 삭제는 확인하지 못했다. 원본 로컬 Git과 전역 작성자 설정은 변경하지 않았다.

## 마켓과 광고 설정

스토어 소개와 실제 실행 화면을 한국어와 영어로 저장하고 API로 다시 읽었다. 무료 가격, 178개 국가 선택과 대상 연령 18세 이상을 확인했다. IARC 콘텐츠 등급과 대상 연령은 별개의 설정으로 기록했다. 앱 콘텐츠 선언 10개가 모두 조치됨으로 표시된다. 남아 있던 앱 카테고리를 교육으로 저장하고 다시 읽었다. 초기 앱 설정이 완료되어 프로덕션 버전 생성 잠금이 해제됐다. 데이터 보안에는 Google 광고 SDK의 대략적인 위치, 앱 상호작용, 진단, 기기 또는 기타 ID의 수집과 공유, TLS와 계정 없음, 광고, SDK 분석 및 부정행위 방지 용도를 신고했다. 별도 제품 원격 분석을 추가했다는 뜻은 아니다. Console CSV 49개 응답의 저장 상태도 대조했다.

개인정보와 지원 페이지 PR seorilabs/seorilabs-official#79는 병합 및 Pages 배포를 완료했다. 한국어와 영어 URL 4개가 모두 HTTP 200이고 실제 앱 본문을 확인했다. Play 개인정보 링크와 데이터 보안 최종 저장, 지원 사이트 주소 저장과 재조회를 완료했다. 관리형 게시가 사용 중지되어 있음을 확인했으며 아직 심사 제출 전이다.

AdMob의 `Memorize All Android GDPR`과 `Memorize All Android US states` 메시지를 해당 Android 앱에만 게시했다. 거부 또는 판매와 공유 거부 옵션을 활성화했다. 기존 다른 앱의 공유 메시지와 iOS 앱은 변경하지 않았다. 제공자의 유럽 메시지 언어 목록에는 한국어가 없어 영어 기본 언어를 사용한다. 실제 UMP 표시는 미실행이다.

정확한 Play 패키지 검색에는 아직 앱이 나오지 않는다. 스토어 연결과 앱별 app-ads.txt 인증, 광고 준비 상태 심사는 미완료다. 공개 app-ads.txt는 www와 루트 도메인에서 HTTP 200이고 게시자 행이 일치하며 robots는 크롤링을 허용한다. 이것을 이 앱의 인증 완료로 기록하지 않는다. 공개 후 검색 결과를 다시 확인한다.

## 산출물 검증과 내부 배포

Linux 릴리스 실행 https://github.com/seoleeapps/memorize-all/actions/runs/39289597630 의 검사와 서명 빌드가 모두 성공했다. 최종 AAB는 76,794,738바이트이고 SHA-256은 `fd8a520c86c5a5b23c4401dadb12637852135f5bf5317cb36cd0b00902492e14`다. AAB, SOURCE_SHA, SHA256SUMS와 ELF 검사 결과를 Actions의 3일 보존 기한 전에 체크아웃 밖에 내려받아 파일을 다시 읽고 대조했다.

실제 manifest에서 패키지, 버전 `1.0.0 (3)`, minSdk 24와 targetSdk 36, 비디버그 상태와 운영 AdMob 앱 ID를 확인했다. AAB의 Expo native 설정에서 운영 모드와 배너 ID를 확인했다. 업로드 키 서명은 Play에서 직접 내려받은 업로드 인증서와 일치했다. 64비트 ELF 46개와 bundle 16KB 설정을 확인했고, 기기 연결 없이 만든 universal APK의 zipalign 16KB 검사를 통과했다. RELRO에는 공식 예외 조건을 적용했다. 실제 16KB 기기 실행은 미실행이다. 독립 검수도 실제 AAB의 서명 엔트리 1,409개와 ELF 46개, 기존 APK의 native 파일 92개와 설정, JS bundle 동일성, 16KB 정렬을 통과했다. 원본 근거 31개 파일을 다시 읽어 해시를 대조했다. `docs/qa/independent-artifact-ad43920.json`에 도구 경고와 잘못된 helper 가정의 수정 이력을 남겼다.

최초 로컬 keytool 실행은 기본 .keystore 파일 부재로 인증서를 출력한 뒤 실패했다. CI와 같은 `-cacerts` 옵션으로 재실행해 검증했다. 키를 새로 만들거나 원본 키를 변경하지 않았다. 산출물 결함으로 기록하지 않으며 이 실행 이력은 정적 검증 근거에 남겼다.

같은 해시의 AAB를 내부 테스트에 올리고 API의 completed 상태와 해시를 다시 읽었다. 콘솔에서도 1.0.0 (3)이 내부 테스터에게 제공됨으로 표시된다. 기기 설치나 실행을 뜻하지 않는다. 같은 versionCode 3을 프로덕션으로 승급해 한영 출시 노트와 전체 출시를 저장했다. 선택 경고는 가독화 파일 부재 한 개이며, Linux 작업 목록에는 minify나 R8 작업이 없다. 임의의 mapping 파일을 만들지 않았다. 프로덕션과 등록정보, 국가 및 지역, 정책 선언 등 변경사항 12개가 게시 개요에 준비됐다. Google의 제출 전 빠른 검사가 진행 중이므로 실제 심사 제출과 승인은 아직 완료로 기록하지 않는다.

## 미실행 범위

사용자 지시로 에뮬레이터와 실기기를 사용하지 않았다. 기기 조회, 설치, 조작, 로그와 화면 수집도 하지 않았다. 실제 네이티브 UMP와 배너, Android 공유 수신과 파일 선택, Play 설치본 실행, 네이티브 글자 크기와 접근성, 16KB 런타임은 미실행이다. 공개 후 실제 설치와 배너 표시는 사용자가 확인한다.

원장은 확인한 각 단계를 따로 기록한다. 공개 완료 검사에 구조 오류는 없지만 공개 완료는 false다. 의존성 보안 권고 4종의 범위와 미수정 사유는 `docs/dependency-audit.md`에 남겼다.
